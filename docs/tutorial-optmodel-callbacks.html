OptModel callbacks

OptModel 以 callback 記錄「如何在 engine 上建立模型」。資料透過 closure 傳入，callback 執行時才操作實際 engine。

var data = OptData.Load(() => new Dataload());

var model = new OptModel("Canonical")
    .AddVariables(engine =>
        engine.BuildVars<VariableB_Assign>(
            data.set_Lot, data.set_Operation, data.set_Eqp))
    .AddObjective(engine =>
        new ObjectiveFunction(/* only required dependencies */).Build(engine))
    .AddConstraints(engine =>
        new Constraint_AssignOne(/* only required dependencies */).Build(engine));

為什麼用 lambda

lambda 把資料依賴固定在組裝點，同時讓 Objective/Constraint 類別只接收實際材料。它不是立即求解；真正執行發生在 OptProject.Execute。

using var project = new OptProject(model)
    .UseConfig(() => projectConfig)
    .UseConfig(() => solverConfig)
    .OnSolved(engine => sink.WriteSolution<VariableB_Assign>(engine));

bool solved = project.Execute();

順序

  1. AddVariables
  2. AddObjective
  3. AddConstraints
  4. OptProject.Execute
  5. OnSolved

Objective 先於 constraints，讓 soft penalty 能依正確的目標方向加入。
