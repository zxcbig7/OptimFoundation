OptimFoundation

.NET 8 的 solver-agnostic MILP framework，提供 CPLEX 與 Gurobi adapter。

一套維度宣告

[OptSet]
[OptDim<string>("From")]
[OptDim<string>("To")]
public sealed partial class Set_Arc { }

[OptParam]
[OptDim<string>("From")]
[OptDim<string>("To")]
public sealed partial class Parameter_ArcCost { }

[OptVar]
[OptDim<string>("From")]
[OptDim<string>("To")]
public sealed partial class VariableB_UseArc { }

Set 至少一維且沒有 QTY；Parameter 可零到多維並固定生成 QTY。OptDim 的泛型參數是 C# 資料型別。

CSV

所有輸入 CSV 都有表頭。

# Set_Arc.csv
From,To
A,B
B,C

# Parameter_ArcCost.csv
From,To,QTY
A,B,12.5
B,C,8

統一讀取

set_Arc = source.Load<Set_Arc>("Set_Arc");
parameter_ArcCost = source.Load<Parameter_ArcCost>("Parameter_ArcCost");

CsvDataSource、InMemoryDataSource 與 DbDataSource 都實作 IDataSource。DB 的名稱引數是完整 SQL。

建立變數

engine.BuildVars<VariableB_UseArc>(data.set_Arc);
engine.BuildVars<VariableC_Produce>(data.set_Product, data.set_Date);
前綴型別預設 bounds
VariableB_Binary[0,1]
VariableC_Continuous[0,1E100]
VariableI_Integer[0,1E100]

限制式

engine.AddLHS(coef, variable);
engine.AddRHS(value);
engine.CreateLessEqual(this, date, employee);

framework 以 owner 類別名與 raw dims 組成 canonical 名稱。模型日期使用 yyyy_MM_dd；CSV 日期使用 yyyy-MM-dd。

組裝

var data = OptData.Load(() => new Dataload());
var model = new OptModel("Canonical")
    .AddVariables(e => e.BuildVars<VariableB_UseArc>(data.set_Arc))
    .AddObjective(e => objective.Build(e))
    .AddConstraints(e => constraint.Build(e));

using var project = new OptProject(model)
    .UseConfig(() => projectConfig)
    .UseConfig(() => solverConfig);

bool solved = project.Execute();
